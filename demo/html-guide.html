whiteout · html guide

Snow in a plain HTML file.

No build step, no bundler, no framework. One script tag and a div. This page is the whole guide, and the panel below is running the real engine.

1. The shortest version

Save this as index.html and open it in a browser. That's it.

<!DOCTYPE html>
<html>
<head>
  <style>
    body { margin: 0; }
    #scene { position: relative; height: 100vh; background: #0a1024; }
  </style>
</head>
<body>

  <div id="scene"></div>

  <script type="module">
    import { createSnowfall, PRESETS } from 'https://esm.sh/whiteout';

    createSnowfall('#scene', PRESETS.classic);
  </script>

</body>
</html>

Why the type="module"? It lets the browser use import. Without it, the import line is a syntax error.

Opening from a file works here. A CDN import is an absolute URL, so file:// is fine. If you switch to a local copy of the package, you'll need a server — browsers block relative module imports over file://.

3. Where the snow goes

createSnowfall appends a canvas inside the element you give it, and makes that element a positioning context. So the snow fills whatever box you point it at.

The target needs a height. A div with no content is zero pixels tall, and zero pixels of snow looks exactly like no snow. 

/* fills the viewport */
#scene { position: relative; height: 100vh; }

/* or just a hero section */
.hero  { position: relative; height: 480px; }

Behind your content

The canvas is absolutely positioned with pointer-events: none, so it won't block clicks. Put your text in a positioned sibling with a higher z-index: 

<div id="scene">
  <h1 style="position: relative; z-index: 1; color: #fff">
    Happy winter
  </h1>
</div>

4. Picking a style

Ten presets. Spread one and override whatever you like:

import { createSnowfall, PRESETS } from 'https://esm.sh/whiteout';

createSnowfall('#scene', {
  ...PRESETS.blizzard,
  wind: 220,      // harder sideways push
  count: 600,     // more flakes
  color: '#dbe9ff',
});
PresetLook
classicSoft round dots, gentle sway
realisticSix-point snowflakes that rotate
blizzardDense, fast, wind-driven streaks
sparkleTiny flickering glitter
glowSoft blurred orbs with bloom
dustBarely-there ambient motes
hailHard ice pellets, fast
auroraSlow teal and violet streaks
confettiMulticolor chips
customYour own image or emoji

5. Making it react to the mouse

createSnowfall('#scene', {
  ...PRESETS.classic,
  interactive: true,
  mouseMode: 'trail',   // 'repel' | 'attract' | 'trail'
  mouseRadius: 140,
  mouseForce: 1.2,
});

trail is the nicest for a hero: flakes get dragged along in the pointer's wake. repel pushes them away like a plough. attract pulls them into a slow vortex.

6. Changing it later

createSnowfall returns a controller. Keep the reference.

const snow = createSnowfall('#scene', PRESETS.classic);

// retune live — no remount, no flicker
snow.update({ count: 400, wind: 100 });

// pause when the tab is hidden, resume when it's back
document.addEventListener('visibilitychange', () => {
  document.hidden ? snow.pause() : snow.resume();
});

// clean up if you're removing the element
// snow.destroy();

7. Wiring it to your own buttons

A small, complete example — a toggle and a density slider:

<div id="scene"></div>
<button id="toggle">Pause</button>
<input id="density" type="range" min="0" max="800" value="150">

<script type="module">
  import { createSnowfall, PRESETS } from 'https://esm.sh/whiteout';

  const snow = createSnowfall('#scene', PRESETS.classic);
  let paused = false;

  document.getElementById('toggle').onclick = () => {
    paused = !paused;
    paused ? snow.pause() : snow.resume();
  };

  document.getElementById('density').oninput = (e) => {
    snow.setCount(Number(e.target.value));
  };
</script>

8. Custom flakes

Any image URL or data URI. For emoji, there's a helper:

import { createSnowfall, PRESETS, emojiFlake } from 'https://esm.sh/whiteout';

createSnowfall('#scene', {
  ...PRESETS.custom,
  customImage: emojiFlake('🍁'),
});

Or write the SVG yourself if you'd rather not import the helper:

const leaf = 'data:image/svg+xml,' + encodeURIComponent(
  '<svg xmlns="http://www.w3.org/2000/svg" width="32" height="32">' +
  '<text y="26" font-size="26">🍁</text></svg>'
);

9. If it's slow

In order of how much it helps:

ChangeEffect
count: 150Fewer flakes. Biggest single lever.
fps: 30Half the frames. Barely visible on falling snow.
pixelRatio: 1Skip the retina buffer. Noticeable on phones.
parallax: falseRemoves the per-flake depth math.

It already pauses when scrolled off screen and when the tab is hidden, so the usual battery complaints shouldn't apply.

10. Accessibility

The canvas carries aria-hidden="true", so screen readers skip it. And if the visitor has reduced motion turned on, you get a single static frame instead of animation — on by default.

If you have a reason to animate anyway:

createSnowfall('#scene', { ...PRESETS.classic, respectReducedMotion: false });

11. With npm instead of a CDN

Same code, just a different import. You'll need a bundler or a dev server, because browsers won't resolve bare package names on their own. 

npm i whiteout

// then, in your bundled file
import { createSnowfall, PRESETS } from 'whiteout';

For React and Next.js, import from whiteout/react instead and use the <Snowfall /> component. See the README for that.
